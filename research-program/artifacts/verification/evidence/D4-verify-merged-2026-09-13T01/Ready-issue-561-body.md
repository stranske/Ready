## Why

In scripts/langchain/issue_dedup.py lines 219-222, _format_similarity computes clamped = min(max(score, 0.0), 1.0) and converts the percentage with round(clamped * 100). In Python, min(max(float('nan'), 0.0), 1.0) returns float('nan'). Passing float('nan') to round() raises ValueError: cannot convert float NaN to integer, causing format_similar_issues_comment to crash whenever a non-finite similarity score is generated by an upstream scoring function or vector search return.

## Scope

- Update _format_similarity in scripts/langchain/issue_dedup.py to check math.isfinite(score) and return a safe fallback (e.g. "0%") for non-finite values.
- Add unit tests in tests/test_main.py covering non-finite float similarity scores.

## Non-Goals

- Altering FAISS vector index construction in scripts/langchain/issue_dedup.py.
- Changing similarity threshold constants.
- Scaffold-only completion does NOT count: catching ValueError around round without validating math.isfinite is a failure of this issue.

## Tasks

- [ ] Guard _format_similarity in scripts/langchain/issue_dedup.py with math.isfinite
- [ ] Add test cases in tests/test_main.py asserting _format_similarity handles float('nan'), float('inf'), and float('-inf') without raising ValueError

## Acceptance Criteria

- `python -c "from scripts.langchain.issue_dedup import _format_similarity; assert _format_similarity(float('nan')) == '0%'"` executes with return code 0.
- `pytest tests/test_main.py` passes all assertions.
- Deliberate-break demonstration: removing the math.isfinite guard causes `pytest tests/test_main.py` to fail on NaN similarity test cases, and reverting restores pass.
