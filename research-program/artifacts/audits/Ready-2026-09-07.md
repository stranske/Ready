## 2. Adversarial Verification & Defect Catalog

### Finding 1: Black Artifact Exclusion Missing in pyproject.toml (P1)
- **Path**: `pyproject.toml:102-105`
- **Defect**: `pyproject.toml` configures `[tool.ruff]` with `extend-exclude = ["research-program/artifacts"]`, but `[tool.black]` lacks an equivalent exclusion rule. Running `black --check .` in push CI fails when machine-generated artifacts are published.
- **Reproducer**:
  ```python
  import tomllib
  from pathlib import Path
  cfg = tomllib.loads(Path("pyproject.toml").read_text())
  black_cfg = cfg.get("tool", {}).get("black", {})
  assert "extend-exclude" not in black_cfg and "exclude" not in black_cfg
  ```
- **Filed**: [stranske/Ready#557](https://github.com/stranske/Ready/issues/557)

### Finding 2: GitHub Models Catalog Discovery Drops Non-OpenAI Publishers (P1)
- **Path**: `tools/discover_model_catalog.py:61-72`
- **Defect**: In `parse_catalog()`, when `provider == "github-models"`, the comprehension filters `if item.get("publisher") == "OpenAI"`. The GitHub Models catalog publishes multi-provider models (Meta, Mistral AI, Microsoft, Cohere). Restricting discovery strictly to OpenAI publisher silently filters out all non-OpenAI models hosted on GitHub Models.
- **Reproducer**:
  ```python
  from tools.discover_model_catalog import parse_catalog
  catalog = [{"id": "meta/llama-3.3-70b-instruct", "publisher": "Meta", "capabilities": ["chat"]}]
  parsed = parse_catalog("github-models", catalog)
  assert len(parsed) == 0  # BUG: Meta model dropped
  ```
- **Filed**: [stranske/Ready#558](https://github.com/stranske/Ready/issues/558)

### Finding 3: Embedding Providers Drop Empty Strings Causing Sequence Desynchronization (P1)
- **Path**: `tools/embedding_provider.py:155, 214`
- **Defect**: Both `OpenAIEmbeddingProvider.embed()` and `LocalFallbackEmbeddingProvider.embed()` filter input texts with `items = [text.strip() for text in texts if text and text.strip()]`. When a caller passes an iterable containing empty strings (e.g. `["foo", "", "bar"]`), the returned vector count diverges (`len(response.vectors) != len(texts)`), breaking 1-to-1 index alignment.
- **Reproducer**:
  ```python
  from tools.embedding_provider import LocalFallbackEmbeddingProvider
  provider = LocalFallbackEmbeddingProvider()
  resp = provider.embed(["first", "", "third"])
  assert len(resp.vectors) == 2  # BUG: Expected 3 vectors
  ```
- **Filed**: [stranske/Ready#559](https://github.com/stranske/Ready/issues/559)

- **Reproducer**:

  from scripts.validate_run_contract import INGEST_SCHEMA_FILES

- **Filed**: [stranske/Ready#560](https://github.com/stranske/Ready/issues/560)

### Finding 5: Unhandled Float NaN in Issue Deduplication Similarity Formatter (P2)
- **Path**: `scripts/langchain/issue_dedup.py:219-222`
- **Defect**: `_format_similarity(score)` computes `clamped = min(max(score, 0.0), 1.0)` and executes `round(clamped * 100)`. When `score` is `NaN`, `round(nan * 100)` raises `ValueError: cannot convert float NaN to integer`, crashing `format_similar_issues_comment()`.
- **Reproducer**:
  ```python
  from scripts.langchain.issue_dedup import _format_similarity
  try:
      _format_similarity(float("nan"))
  except ValueError as exc:
      pass  # BUG: Raised ValueError
  ```
- **Filed**: [stranske/Ready#561](https://github.com/stranske/Ready/issues/561)

### Finding 6: Non-Finite Confidence Values Bypass Human Review Gate in Verdict Policy (P2)
- **Path**: `scripts/langchain/verdict_policy.py:73-88, 177-181`
- **Defect**: `_coerce_confidence()` and `_normalize_confidence()` allow `NaN` values to pass through. When `_split_pass_concerns()` encounters a `concerns` verdict with `NaN` confidence, comparing `nan >= 0.85` evaluates to `False`, silently bypassing `needs_human=True` on dissenting split provider verdicts.
- **Reproducer**:
  ```python
  from scripts.langchain.verdict_policy import ProviderVerdict, evaluate_verdict_policy
  v1 = ProviderVerdict(provider="openai", model="gpt-5", verdict="Pass", confidence=0.95)
  v2 = ProviderVerdict(provider="anthropic", model="claude", verdict="Concerns", confidence=float("nan"))
  res = evaluate_verdict_policy([v1, v2], policy="worst")
  assert res.needs_human is False  # BUG: Dissenting concerns bypassed
  ```
- **Filed**: [stranske/Ready#562](https://github.com/stranske/Ready/issues/562)

### Finding 7: CI Failure Triage Links to Non-Existent Integration Guide (P2)
- **Path**: `tools/ci_failure_triage.py:79, 93, 107`
- **Defect**: `DEFAULT_TRIAGE_PATTERNS` defines `playbook_url` pointing to `docs/INTEGRATION_GUIDE.md`, which does not exist in the repository (the real guide is `docs/CI_SYSTEM_GUIDE.md`), generating 404 dead links in automated triage comments.
- **Reproducer**:
  ```python
  from pathlib import Path
  from tools.ci_failure_triage import DEFAULT_TRIAGE_PATTERNS
  for p in DEFAULT_TRIAGE_PATTERNS:
      if p.playbook_url:
          doc = Path(p.playbook_url.split("#")[0])
          assert not doc.is_file()  # BUG: Dead link
  ```
- **Filed**: [stranske/Ready#563](https://github.com/stranske/Ready/issues/563)
