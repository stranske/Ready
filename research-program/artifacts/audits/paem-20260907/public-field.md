# Public field, opportunities and tools — dimensions 5–7
Checked 2026-09-07. Primary documentation only; selected comparator scan, not an exhaustive market ranking.

- NumPy SeedSequence and parallel RNG guidance: https://numpy.org/doc/stable/reference/random/bit_generators/generated/numpy.random.SeedSequence.html and https://numpy.org/doc/2.3/reference/random/parallel.html. PAEM already has stable name-keyed substreams in pa_core/random.py:61-128; preserve this, no RNG-library replacement proposed. No claim of cross-version bitwise replay.
- SciPy bootstrap: https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html. Provides confidence intervals and standard error, with paired observations and a resampling axis. Candidate use: validate precision of tail metrics by resampling independent paths, preserving within-path dependence. This is an option to investigate, not a mandatory dependency or a guarantee of calibrated rare-tail inference.
- Streamlit AppTest: https://docs.streamlit.io/develop/api-reference/app-testing/st.testing.v1.apptest . Existing framework supports application-driven assertions and multipage navigation. Some secondary Streamlit guides contradict the current reference on multipage/file-upload support; use the installed version and actual probes as evidence. Reuse for first-run and state handoff tests; browser evidence remains needed for layout/export interactions.

The prior closed issue 1917 requested MC standard errors and convergence diagnostics; both are implemented, so no duplicate feature request. New calibration probe observes only 81.0% empirical coverage for the nominal 95% CVaR interval over 1000 independent normal samples of size 2000 (seed 20260907); matched mean interval control covers 95.9%. This justifies a bounded estimator-calibration follow-up, subject to final source/adversarial verification.

Roadmap candidates (optional, not bugs): independent-path resampling plus parameter uncertainty; high-water-mark/transaction-cost extension only after actual owner use case (monthly fee crystallization is documented); a self-contained shareable scenario comparison view from existing run artifacts, aligning work-side static HTML and local Python. No hosted service or database necessary for these selected goals. These require product design before implementation issues; no new dependency is approved merely by this audit.
