- **Reproduction:**
  ```bash
  cd Orchestrator/src
  python3 -c "
  import sqlite3, tempfile, os, copy, execution_profiles as ep
  old = copy.deepcopy(ep.PROFILE_REGISTRY)
  s = copy.deepcopy(old['codex-5.6-sol-high']); s['lifecycle_status']='active'; s.pop('successor_profile_id',None)
  old['codex-5.6-sol-high']=s; old.pop('codex-6-astra-high',None)
  td=tempfile.mkdtemp(); conn=sqlite3.connect(os.path.join(td,'t.db'))
  conn.executescript(ep.SCHEMA)
  for p in old.values():
    p=ep.validate_profile(p); conn.execute('INSERT INTO execution_profiles VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?,?,?)',
      (1,p['profile_id'],p['agent'],p['provider'],p['requested_model'],p['reasoning_effort'],p['permission_mode'],
       ep._canonical(p['transport_support']),p.get('legacy_adapter_mode'),p['adapter_version'],p['prompt_version'],
       p['lifecycle_status'],p.get('successor_profile_id'),ep._canonical(p),1))
  conn.commit(); ep.ensure_schema(conn)  # ValueError
  "
  ```
  Also: `pytest tests/test_evidence_contract_compiler.py::test_evaluator_prompt_and_generated_issue_are_contract_aware` fails on non-fresh local DB.
- **Why tests miss it:** New-install tests pass; no migration test for lifecycle transitions on existing rows.
- **Merge-risk:** **Block Orchestrator merge** for unattended hosts with existing orchestrator DB (router/dispatcher/trial paths calling `ensure_schema`).
- **Owner:** closer fix (lifecycle migration or schema-version bump with UPDATE path)
